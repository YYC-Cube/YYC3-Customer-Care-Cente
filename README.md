## 📋 项目概述 | Overview

**中文**

YYC³ Customer Care Center（YYC3-CCC）是基于「五高五标五化」理念构建的现代化 AI 代理服务客户关怀中心。采用 Next.js 15 App Router 构建，集成国际化系统、动画效果和响应式设计，为企业提供智能、高效、安全的客户服务解决方案。

**English**

YYC³ Customer Care Center (YYC3-CCC) is a modern AI-powered customer care center built on the "Five High, Five Standard, Five Transformation" philosophy. Powered by Next.js 15 App Router with internationalization, animations, and responsive design, it delivers intelligent, efficient, and secure customer service solutions for enterprises.

## 🚀 核心特性 | Key Features

### 智能服务 | Intelligent Services

- **AI 代理服务 | AI Agent Services**: 智能客服、智能表单、智能数据分析 / Smart customer service, smart forms, intelligent data analysis

## 📦 快速开始 | Quick Start

### 环境要求 | Prerequisites

- Node.js 22+
- pnpm 10+

### 安装 | Installation

```bash
# 克隆仓库 | Clone repository
git clone https://github.com/YYC-Cube/YYC3-Customer-Care-Cente.git

# 进入项目目录 | Enter project directory
cd YYC3-Customer-Care-Center

# 安装依赖 | Install dependencies
pnpm install
```

### 开发运行 | Development

```bash
# 启动开发服务器（端口 3204）| Start dev server (port 3204)
pnpm dev

# 构建生产版本 | Build for production
pnpm build

# 预览生产构建 | Preview production build
pnpm start

# 代码格式化 | Format code
pnpm format

# 代码格式检查 | Check formatting
pnpm format:check

# 代码检查 | Lint
pnpm lint

# 类型检查 | Type check
pnpm type-check

# 运行测试 | Run tests
pnpm test

# 运行单元测试 | Run unit tests
pnpm test:unit

# 生成测试覆盖率报告 | Generate coverage report
pnpm test:coverage
```

### 部署 | Deployment

#### GitHub Pages（默认）| GitHub Pages (Default)

项目配置为自动部署至 GitHub Pages，自定义域名 `ccc.yyc3.top`：

1. 推送至 `main` 分支触发自动部署
2. GitHub Actions 自动构建并部署
3. DNS 已配置指向 GitHub Pages

#### Docker 部署 | Docker Deployment

```bash
# 使用 Docker Compose 启动所有服务 | Start all services
docker-compose up -d

# 查看服务状态 | Check service status
docker-compose ps

# 查看日志 | View logs
docker-compose logs -f

# 停止服务 | Stop services
docker-compose down
```
